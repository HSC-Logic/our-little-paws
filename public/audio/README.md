# Our little soundtrack

These three instrumental WAV loops are original procedural compositions created for this application by `scripts/generate-audio.mjs`. They use synthesized sine harmonics, with no external samples or recordings. The project author may use, modify, and distribute these generated audio assets with the application.

Regenerate with `node scripts/generate-audio.mjs`. Playback begins after a Play gesture and remains local to each device. Shared track selection does not synchronize playback position.
